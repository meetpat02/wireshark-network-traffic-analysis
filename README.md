# Network Traffic Analysis Using Wireshark

## Project Overview

This project explores network traffic using Wireshark. The goal is to
understand how devices communicate over a network and analyze common
network protocols such as DNS, TCP, HTTP/HTTPS, and TLS.

## Objectives

- Capture live network traffic using Wireshark
- Identify common network protocols
- Analyze DNS requests and responses
- Examine TCP connections
- Understand source and destination IP addresses
- Identify ports used by different network services
- Document observations and potential security implications

## Tools

- Wireshark
- macOS
- Google Chrome
- GitHub

## Analysis

### DNS Traffic

DNS converts domain names into IP addresses. I captured DNS traffic
while visiting websites and examined the DNS queries generated by my
computer.

### TCP Traffic

TCP provides reliable communication between devices. I examined TCP
packets to better understand how connections are established between
my computer and remote servers.

## What I Learned

This project helped me develop a better understanding of how network
traffic moves between devices and how tools such as Wireshark can be
used to inspect network communication.
